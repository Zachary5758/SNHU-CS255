# SNHU-CS255
The DriverPass project involved designing a system to help students prepare for driving tests through online classes, practice tests, and driving lessons.

I feel as though I did well creating UML diagrams to show how the system would work and how users would interact with it. If i could revise something, I would spend more time reviewing the diagrams to make sure everything was clear and accurate.

I used the client's requirements to decide what features the system needed, including appointment scheduling, instructor assignments, and tracking studenbt progress. Understanding user needs is important because the system should solve the client's actual problems.

My approach to software design is to gather requirements first, organize the information with diagrams, and review the dsign before moving foward. In the future, I would continue using UML diagrams and feedback to improve my designs.
